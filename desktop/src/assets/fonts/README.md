# Bundled editor fonts

Regular WOFF2 fonts are served from the app for offline use. Their unmodified
licenses (SIL Open Font License 1.1) are in `public/licenses/fonts` and are copied
into the app's build output.

- JetBrains Mono 2.304: [official repository](https://github.com/JetBrains/JetBrainsMono/tree/v2.304), `fonts/webfonts/JetBrainsMono-Regular.woff2`.
- Fira Code 6.2: [official release](https://github.com/tonsky/FiraCode/releases/tag/6.2), `woff2/FiraCode-Regular.woff2`.
- Cascadia Code 2407.24: [official release](https://github.com/microsoft/cascadia-code/releases/tag/v2407.24), `woff2/static/CascadiaCode-Regular.woff2`.
- Source Code Pro: [official release branch](https://github.com/adobe-fonts/source-code-pro/tree/release), `WOFF2/OTF/SourceCodePro-Regular.otf.woff2` (downloaded 2026-10-26).

Menlo and Consolas use installed system fonts and are not redistributed.
